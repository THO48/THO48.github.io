# Skill：荒诞因果随机发疯生成器 v2

## 核心原则
不要按固定段落顺序写。
不要每次都“为什么开头 → 究其根本 → 不仅 → 毕竟 → 所以 → 否则 → 结尾”。
每次生成前，先在内部随机抽取：开头、锚词、干扰词、伪术语、时间、数量、债务/情感、连接词、结尾。
然后把这些元素随机串成一张“因果网”，允许倒装、插入、回指、中途换主角、把前文词重新定义。

## 内部随机流程（不输出）
1. 随机决定开头类型：从开头池抽 1 个，连续两次不得重复。
2. 随机抽 3 个锚词：必须出现，且至少一个词出现两次，但属性可以变。
3. 随机抽 5—8 个干扰词：至少出现一次。
4. 随机抽 3—6 个伪学术/技术词。
5. 随机抽 1 个时间、1 个数量、1 个债务/情感关系词。
6. 随机抽 4—8 个因果连接词。
7. 随机决定因果层数：2—4 层，顺序打乱。
8. 随机决定是否倒装、是否自指、是否中途换主语、是否在结尾把前面全部推翻。
9. 随机选结尾池 1 个。
10. 检查：如果和上一条开头/结尾/连接词太像，重抽。

## 开头池（随机抽，概率均等，禁止连续重复）
- 为什么 A 在 B 的时候，C 会 D？
- 强烈不建议用 A 去 B C。
- 千万不要试图给 A 涂/喂/安装 B。
- 如果 A 开始 B，那么 C 就会 D。
- 据不完全统计，A 在 B 时，C 会 D。
- 警告：A 和 B 一旦 C，D 就会 E。
- 没有人告诉你，A 其实一直在 B C。
- 当 A 把 B 做成 C，D 就会 E。
- A 之所以 B，是因为 C 在 D 里 E。
- 你以为 A 是 B？其实它正在 C D。

## 因果连接池（随机抽，打乱顺序，可重复但不得连续）
因为、所以、导致、不仅、还会、否则、毕竟、因此、与此同时、更离谱的是、换句话说、结果就是、于是、从而、迫使、究其根本、当……时、只要……就、如果……那么、然而、而且、甚至、直到、除非、不然、单方面撕毁、自动长出、被迫接入、暂时切换、试图证明。

## 结尾池（随机抽，连续两次不得重复）
- 所以，不是 A 要 B，而是你的句子在 C。
- 一句话：没有为什么，只有语言在 D。
- 因此，不是 E 导致 F，而是语法在 G。
- 所以，不是 A 和 B 要 C，而是你的标点符号在 D。
- 总之，这一切只是因为频率在 E，虫洞在 F。
- 换句话说，不是 A 疯了，是主语和谓语在 B。
- 最终，不是 A 决定 B，而是 C 把 D 压缩成了 E。
- 也就是说，不是 A 在 B，而是整个语法系统在 C。

## 硬规则
1. 每句至少发生 3 次范畴跳跃。
2. 必须出现至少 5 个伪学术/技术词。
3. 必须出现至少 1 个数量、1 个时间、1 个债务/情感词。
4. 禁止连续使用同一开头、同一结尾、同一连接词。
5. 禁止固定“开头—究其根本—不仅—毕竟—所以—否则”顺序。
6. 允许中途换主语、把前文词重新定义、倒装、插入、回指。
7. 结尾必须归因给语言、语法、标点、频率、虫洞、主语谓语或整个句子本身。
8. 不解释、不道歉、不承认荒谬。
9. 输出一段话，80—300 字，随机长度。
10. 若用户给主题词，主题词必须出现，但其他全部随机。

## 调用方式
用户输入：
- 随机生成一条
- 随机生成一条，疯狂度 5
- 随机生成一条，锚词：咖啡机、企鹅、路由器
- 随机生成一条，不要用“为什么”开头，主题：微波炉、二维码、消防栓

你直接输出正文，不要展示随机过程。
